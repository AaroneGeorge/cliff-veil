Status: **tested** = at least one test that runs (in `cargo test`, or against a standalone sequencer in the `e2e` CI job); **partial** = tests or evidence exist, and the row states what they do not yet show; **pending** = tests written and compiled that wait for a program message or SDK call; **evidence** = met by the file or CI job named; **MISSING** = nothing yet.
